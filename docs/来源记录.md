# 来源记录（外部设计、数据与代码的来源台账）

> **版本**：与方案 `v3.13` 对应 ｜ **建立时机**：M0 的**流程 B**
>
> ## 这个文件解决什么问题
>
> 本项目借鉴了 12 个参照项目的**设计、数据与（少量）代码**。**"借鉴"必须有据可查**，否则：
> ① 无法回答"这个设计是谁先做的"；② 无法判断许可风险；③ 无法在对方更新时判断要不要跟进。
>
> **三条纪律**（与方案 §1.4 红线表、M0 流程 B 一致）：
> 1. **AGPL 项目只读设计，零代码引用**；自定义许可项目（PCL 系）**只做事实提取**。
> 2. **同一许可**（GPL-3.0）项目可借鉴代码，但**必须保留原作者声明**并记入本文件。
> 3. **CI 必须能检测误粘贴**：对 `repos/` 源码做行哈希，与 `src/`、`crates/` 比对，命中即失败。

## 5. 零代码引用（**本项目对所有"非许可兼容"来源的统一纪律**）

> **本节是对 §2.3 与 §3 的执行规则，也是产品负责人 2026-10-01 确认的口径。**

| # | 规则 |
|---|---|
| **1** | **只借鉴机制、不复制表达。** 机制 / 算法 / 架构思想 / 数据格式**不受版权保护**；**具体代码、注释措辞、文案、界面像素**受 |
| **2** | **读别人的代码是为了"知道有这种做法"，不是为了"省打字"。** 实现由我们自己写 |
| **3** | **主动标注来源**（如本文件 R 系列）。**"模糊地不提"比"明确标注"风险更高**——标注说明我们是独立实现，不标注反而像隐瞒 |
| **4** | **文案、界面文字、字符串常量一律自己写**。尤其 PCL 的 62+39 条中文文案（ADR-0011） |
| **5** | **若某天确需复制代码** → **先查它的许可是否兼容**，再按 §2.1/§2.2 登记，并**保留原声明**。**不许"先抄了再说"** |

**受这条约束的来源**：MoLaunch（自定义许可）· PCL / PCL-CE（自定义）· Portal 与 `nx-dl-engine`（AGPL）· NexBox（GPL-3.0）· Axolotl（GPL-3.0）等。
**不受约束**（可复制并已登记声明）：`@xmcl/semver`（Apache-2.0）· Trident（MIT）等，见 §2.1。
