# 归档：界面效果图的全部历史版本

本目录保存**每一轮界面稿**，可追溯"某一版长什么样、当时为什么改"。
**当前定稿在上一级**：`home-final.png` / `settings-home-plugins.png`（源：`home-final.html`）。

## 命名

`vNN-...`，NN 为轮次。**同轮多次渲染用 `vNN-k-...`**。

| 组 | 内容 |
|---|---|
| `v00-*` | 最早两轮（`interface-mockup` / `island-states` / `sidebar-final` / `preset-C` / `preset-E` / `final-*`）。**已被后续全部取代** |
| `v02-*` | 仿官方启动器布局的第一版（左栏 = 账户 + 产品 + 导航 + 大横幅 + 右栏） |
| `v03-*` | 主界面 v3 四屏；`v03-threecol-*` 是三栏（启动器栏 / 分组栏 / 列表）的两个方案 |
| `v04-*` | 把"分组"放进左栏（**这是错的一版**：一级选主页却挂了实例的分类） |
| `v05-*` | 层级修正：一级导航 / 产品 / 分组各占一栏 |
| `v06-*` | 主页去分组、实例页才有分组 |
| `v07-*` | 四页对应关系（`v07-0-rule` 是规则表），配 UI 规格 §4.6.1.1 |
| `v08-*` | 二级分类区可滚动（含 14 个分组的滚动演示） |
| `v09-*` | 主页分段（最近运行 / 收藏 / 新闻 / 更新日志） |
| `v10-*` | 首页卡片式小部件（**内容是抄参考图的**，已废弃） |
| `v11-*` | 小部件改为我们自己的内容（游玩统计 / 我的分组 / 下载队列 / 实例体检） |
| `v12-*` | 横幅回顶 + 右侧插件栏可滚动 |

## 为什么留着而不删

界面稿的价值**不在好看，而在"记录当时的选择与代价"**。
例如 `v04-*` 与 `v07-0-rule.png` 一起看，就能明白
**"一级选主页、二级却挂实例分组"这个错误为什么会发生**（想把空白填上）——
这已经写进 UI 规格 §4.6.1.1，而那条规定正是从这一版换来的。

## 与 S1 的区别

同级目录 `S1/` 是**尖刺实测证据**（材质是否生效的像素分析），**不是设计稿**，因此不归档。
