## 顺带一件事（只有开开关能做）

官方启动器的设置里有四个开关，**当前状态**（我从 `launcher_profiles.json` 读到的）：

| 开关 | 当前 | 打开后可能出现什么 |
|---|---|---|
| `enableAdvanced` | **关** | 高级选项（可能含 Java 路径/JVM 参数） |
| `enableHistorical` | **关** | 历史版本 |
| `enableSnapshots` | 关 | 快照 |
| `enableReleases` | **开** | 正式版 |

**如果你愿意**：把 `enableAdvanced` 打开，再截一张设置页（`9-高级设置.png`）。
**这张最有价值** —— 它可能揭示**官方启动器有没有暴露 Java 路径与 JVM 参数**，
而那正是我们 M2/M3 要对标的地方。

它只能证明"这次会话没调用"，不能证明"界面里没有"。

| 我的结论 | 依据强度 | 你的一张图能做什么 |
|---|---|---|
| Java 版没有内容管理 | **弱**（0 命中） | **找到就推翻我** |
| 没有本地世界管理 | **弱**（0 命中） | **找到就推翻我** |
| 皮肤只能看不能换 | **弱**（0 命中） | **找到就推翻我** |

**所以：如果你在界面上看到了我以为不存在的东西，那比确认十次都有价值。**
