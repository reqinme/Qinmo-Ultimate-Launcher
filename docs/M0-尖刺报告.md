# S1 尖刺报告：DWM 材质 × 窗口边框

> **日期**：2026-10-01 ｜ **对应**：`docs/M0-尖刺任务书.md` **S1**（U1）｜ **结论去向**：`docs/UI设计规格.md` §11.2 的 A / B1 / B2 三档

> **状态**：**已出结论，A 档成立**（无边框 + 材质可用）

## 1. 结论（先说结果）

| 问题 | **答案** |
|---|---|
| **无边框窗口能不能用 Mica** | ✅ **能**。`decorations: false` + `apply_mica` 返回 `Ok`，且**有可见效果** |
| **无边框窗口能不能用 Acrylic** | ✅ **能**（同上） |
| **第三种材质 Tabbed** | ✅ 也能，且观感与 Mica/Acrylic **可区分**（中心亮度 216.2 vs 242.5 / 144.4） |
| **材质是否随系统主题自动明暗** | ✅ 是。系统浅色时 `dark=None` 与 `dark=false` 结果**完全一致**（均为 242.5） |
| **有没有出现黑边/白边/渲染破裂** | ✅ 没有。所有色块边缘干净 |
| **走哪一档预案** | **A 档**（`docs/UI设计规格.md` §11.2）：岛贴顶居中、浮在自绘标题栏之上 |

**因此 §4 的布局可以按 A 档冻结**——这是 S1 要解开的那个阻塞。

## 2. ⚠️ 一个必须先说的前提：**光调 API 是不够的**

**第一次跑矩阵时，8 格全部 `apply_ok: true`，但像素分析显示它们与"完全不调材质"的对照组数值一模一样。**

第一轮的实测数据（**窗口内部中心区**）：

```
cell                     ctr_mean  ctr_sd
mica-bare-auto                255       0
none-bare-auto   ← 对照组      255       0      ← 与 Mica 完全相同
tabbed-bare-auto              255       0
```

**纯白 255、标准差 0，且 Mica 那格与对照组无差别** → 材质**没有任何可见效果**。

**根因**：**Tauri 的 WebView2 默认以不透明背景填充窗口**，把 DWM 材质整个盖住。
`apply_mica` 改的是**窗口**属性，而窗口被一层不透明内容填满 → 看不见。

**修法**：窗口构建时加 **`transparent(true)`**。

```rust
tauri::WebviewWindowBuilder::new(...)
    .decorations(decorations)
    .transparent(true)      // ← 少了这个，材质看得见才怪
    .build()?;
```

> ### 🔴 这条是本尖刺最重要的产出，比"材质能用"本身更重要
>
> 如果我只信 `apply_ok: true`，结论会是"材质可用"，而**实际现象是完全不可见**。
> **`apply_*` 返回 `Ok` 只说明 Windows 接受了这个调用，不说明它产生了任何可见效果。**
>
> 这与本项目已经栽过两次的失效模式**同源**：
> 用比真实条件宽松的证据（`HTTP 200`、带 flag 的截图、`apply_ok`）替代"看到结果"。
> **所以本次的判据被强制为：像素分析 + 看图，`apply_ok` 只作参考。**

## 3. 完整矩阵实测数据

**环境**：Windows 11 家庭版 中文版 **Build 26200** ｜ 系统主题**浅色**（`AppsUseLightTheme=1`）｜
透明效果**开**（`EnableTransparency=1`）｜ 显示缩放 **150%**（请求 1100×760 → 实得 1650×1140）｜
`tauri 2.12.1` · `window-vibrancy 0.8.1` · WebView2 154.0.4258.37

**像素统计口径**：屏幕截图中**窗口内部中心区**（水平 30–70%、垂直 60–80%）的亮度均值。
**对照组** `none-bare-auto` = **不调用任何材质 API**。

| 格子 | 材质 | 边框 | `dark` | `apply_ok` | **中心均值** | 与对照组差 | 判定 |
|---|---|---|---|---|---|---|---|
| `none-bare-auto` | **无（对照）** | 无 | — | — | **12.0** | — | 基线（窗口近乎全透） |
| `mica-bare-auto` | Mica | **无** | 未指定 | ✅ | **242.5** | **+230.5** | ✅ **生效** |
| `mica-deco-auto` | Mica | **有** | 未指定 | ✅ | **242.5** | +230.5 | ✅ 生效（与无边框同值） |
| `mica-bare-light` | Mica | 无 | `false` | ✅ | **242.5** | +230.5 | ✅ 生效（与 auto 同值，自洽） |
| `mica-bare-dark` | Mica | 无 | `true` | ✅ | **31.1** | +19.1 | ✅ **生效，且明显更暗** |
| `acrylic-bare-auto` | Acrylic | 无 | — | ✅ | **144.4** | +132.4 | ✅ 生效，整体偏暗（含着色） |
| `acrylic-deco-auto` | Acrylic | 有 | — | ✅ | **139.0** | +127.0 | ✅ 生效 |
| `tabbed-bare-auto` | Tabbed | 无 | 未指定 | ✅ | **216.2** | +204.2 | ✅ 生效，观感**可区分** |

**读法**：**只要某一格的中心均值显著偏离对照组 `12.0`，就说明材质产生了可见效果。**
六种材质配置给出**六个互不相同、且可复现**的数值 → 材质确实在起作用。

**边框维度（有/无）对材质没有影响**：Mica 两格都是 242.5，Acrylic 两格 144.4 / 139.0（差 5.4，属截图噪声量级）。
**这正是要紧的那一点**：`decorations: false` **不会**让材质失效。

**未定论的一项**（见 §5）：**窗口四周边缘是否透出桌面**。本次数据不足以判定，
因为截图把窗口外 12px 也框进来了，边缘读数混入了窗口外的像素。

## 4. 复现方式

```powershell
# 构建（首次约 3–5 分钟，拉 Tauri 全家桶）
cargo build --manifest-path spikes/s1-material/Cargo.toml

# 跑矩阵：8 格，逐格开窗、调材质、截图
powershell -File spikes/s1-material/capture-matrix.ps1

# 像素分析：与对照组比较，输出 matrix-analysis.json
powershell -File spikes/s1-material/analyze-matrix.ps1

# 单跑一格（调试用）
spikes/s1-material/target/debug/s1-material.exe --material mica --decorations --result out\r.json
```

**产物**：`spikes/s1-material/out/` 下的 `shot-*.png`（屏幕截图）、`shot-*.printwindow.png`、`result-*.json`、`matrix-analysis.json`。

## 5. 本次没解决 / 需要后续注意的

| # | 事项 | 为什么没解决 | 何时处理 |
|---|---|---|---|
| 1 | **边缘是否透出桌面**（材质是"半透"还是"不透明染色"） | 截图把窗口外 12px 一起框了进来，边缘读数不纯。**要判定必须在窗口上留出足够大的纯透明区，并把截图严格裁到窗口内陆** | 若 §4 要用"透出桌面"的观感（Acrylic 的卖点）则在 M4 前补测；**若只用 Mica 的"染色"观感则不影响 A 档结论** |
| 2 | **材质对冷启动与内存的增量** | 属 **S3** 的范围（性能基线），本尖刺不测 | **U4（S3 阶段 B）** |
| 3 | **150% 缩放下的观感** | 已确认窗口按 1.5 倍放大（1100→1650），但"字体/描边在高分屏是否发虚"属 §3.3 的实现验证 | M4 的门禁项 |
| 4 | **深色主题下的文字可读性** | 本尖刺的测试页是为浅色底设计的（深色字）。截图证实**深色 Mica 下深色字不可读**——但这是**测试页的问题，不是材质的问题** | M4：主题令牌必须四态齐备（已在 UI 规格 §5.2） |
| 5 | **PrintWindow 取不到 DWM 合成内容** | 实测：`PrintWindow(..., 2)` 对无边框 + Mica 返回**近全白** | 已记入工具经验：**验证 DWM 材质只能用屏幕截图，不能用 PrintWindow** |
