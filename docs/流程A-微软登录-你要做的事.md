# 流程 A · 微软正版登录 · 你要做的事（一页清单）

> **状态**：用户已确认 **「要微软正版登录」**（2026-10-01）
> **因此**：M0 出口条件 #4 由「条件项」转为**实项**，Azure 应用注册 + Mojang 审批**必须提交**
> **为什么现在就做**：**它有外部等待期**（任务书原文：*"放在 M5 才启动会直接卡住里程碑"*）
> **M0 的要求只是"提交完成"，不要求审批通过** —— 所以这件事**今天就能推进到边界**，
> 剩下的等待不由我们控制。

---

## 你只需要做两件事

### 第 1 件 · 在 Azure 门户注册一个应用

| 项 | 填什么 |
|---|---|
| 应用类型 | **公共客户端**（Public client） |
| 关键开关 | **启用「允许公共客户端流」**（Allow public client flows = 是） |
| 重定向 URI | 用**环回地址**（如 `http://localhost` 或 `http://127.0.0.1`）—— 桌面应用的标准做法 |
| 需要密钥吗 | **不需要**。公共客户端不使用客户端密钥（用不了密钥，也不该用） |
| 要记录什么 | **`client_id`（应用程序/客户端 ID）** |

> **不要做的事**：不要建"机密客户端"，不要生成客户端密钥，不要开放任何"代表用户读取所有邮件/文件"之类的 API 权限。
> 我们只需要 **XboxLive.signin** 这一类登录范围，正式范围以 Mojang 审批通过后给的要求为准。

### 第 2 件 · 按 Mojang 的流程提交申请

Mojang 的官方入口（任务书里给的链接，原文照录）：

> https://help.minecraft.net/hc/en-us/articles/16254801392141

提交时要记录三样：**提交时间**、**申请编号**、**当前状态**。

## 交给我什么

把下面这段填了发我就行（**不确定的项写"不确定"也很有用**）：

```
client_id：________________
提交时间：________________
申请编号：________________
当前状态：________________
```

我拿到后会做三件事：

1. 填进任务书 §「流程 A」的结论槽（`docs/M0-尖刺任务书.md`）；
2. 把 `client_id` 落到**配置而不是代码**里 —— 否则审批中途通过时得改代码重编译；
3. **现在就把"审批未通过"的降级路径实现掉**（按任务书的规则）：
   界面**不是隐藏、也不是灰按钮**，而是**带原因的禁用态**：
   `{ enabled: false, reason: "微软正版登录需应用审批通过，当前状态：<状态>" }`
   这样**审批通过后不需要改一行代码**，只改运行时读到的状态。

## 我会自己准备的部分（你不用管）

本项目的 `docs/身份与授权规格.md` §1.3 已定**四种身份来源**：

| 身份来源 | 依赖流程 A 吗 |
|---|---|
| 微软正版登录 | ✅ **依赖** |
| 离线账户 | ❌ 不依赖 |
| 统一通行证（LittleSkin 一类） | ❌ 不依赖 |
| Authlib 外置登录 | ❌ 不依赖 |

**所以流程 A 的等待期不阻塞开发**：另外三种身份来源可以在等待期间照常实现，
而它们共用同一套"账户层 / 授权层"结构（见该规格 §1.3）。
**这也是为什么现在提交就够、不必等审批结果。**

## ⚠️ 一条我必须提前说清的边界

**"不做红线上写的事"这条约束，在正版登录上尤其容易踩**：

| 绝不做的 | 为什么特别要在这里说 |
|---|---|
| 伪造官方会话 / 劫持授权 / 破解登录 | 这是本项目最根本的边界 |
| 转分发游戏内容 | 与登录无关，但同属一条红线族 |
| 滥用 Mojang / Microsoft 的品牌与标识 | 审批期间尤其敏感 —— 界面上不能暗示"官方认可" |

**而 S9 已经抓到一个真实的对照案例**（记在 `docs/_artifacts/S9/`）：
参照项目 LeviLauncher 在 `internal/uwp/auth_key.go:16-22` **硬编码并替换了游戏的
Xbox 授权公钥**（注释里引用第三方 KeyPatcher），而且 `ensureLegacyAuthKey`
跑在**正常部署路径**里（`internal/uwp/deploy_windows.go:266`、`internal/uwp/extract.go:240`）
—— 那是一次**商店授权绕过**。
**我们只把它当"别人踩过的坑"记录，不采用它的任何相关做法。**
